## 🎡 Рулетка Analytics PRO

Профессиональный инструмент для анализа статистических аномалий и вероятностей в европейской рулетке. Система отслеживает текущие серии выпадений и рассчитывает риск прерывания аномальных цепочек в реальном времени.

### 🚀 Основные возможности

* **Мониторинг серий (Streaks):** Автоматический подсчет текущей длины серии для цветов, четности, половин и дюжин.
* **Расчет Риска:** Математическая оценка вероятности того, что текущая серия прервется следующим броском (базируется на формуле кумулятивной вероятности).
* **Цветовая индикация аномалий:**
    * 🟢 **< 70%**: Нормальное состояние.
    * 🟡 **70% - 90%**: Внимание, назревает аномалия.
    * 🔴 **> 90%**: Критическое отклонение (высокое ожидание возврата к среднему).
* **Глубокая статистика чисел:**
    * **Σ (Sigma):** Общее количество выпадений каждого числа.
    * **Δ (Delta):** Интервал (количество бросков) с момента последнего появления числа.
* **Двойной интерфейс:**
    * **Табличный вид:** Структурированная статистика по категориям с таблицей всех чисел.
    * **Вид Рулетки:** Интерактивный стол казино с кликабельными числами и выставками.
* **Удобный интерфейс:** Фиксированная панель ввода, бесконечная история бросков и сортируемая таблица результатов.

### 📊 Математическая логика

Система использует классическую формулу вероятности для независимых событий. Например, для серии из $n$ событий одного типа с вероятностью $p$, вероятность продолжения серии рассчитывается как $p^{n+1}$.

**Риск прерывания** вычисляется как $1 - p^{n+1}$, что позволяет наглядно увидеть "натяжение струны" при длительных повторениях.

## 🃏 Poker Odds Calculator (Monte Carlo Engine)

Профессиональный движок для расчета вероятностей в покере (Texas Hold'em), работающий на основе статистического моделирования. Система анализирует текущую руку игрока, карты на столе и карты оппонентов, выдавая точный прогноз на победу (Equity) и детализированные вероятности по каждой комбинации.

### 🧠 Математическая модель

В основе калькулятора лежит **метод Монте-Карло**. В покере количество возможных комбинаций оставшихся карт может исчисляться миллиардами, что делает прямой перебор (брутфорс) невозможным для веб-инструмента реального времени.

### Как производятся вычисления:

1. **Исключение известных карт**: Из стандартной колоды (52 карты) извлекаются карты игрока (Hero), общие карты (Board) и карты оппонентов.
2. **Многократная симуляция**: Движок проводит **100,000 итераций** случайных раздач.
   * Достраивает Board до 5 карт из остатка колоды.
   * Если руки оппонентов неизвестны, им сдаются случайные карты из остатка колоды.
3. **Статистический анализ**: Equity (шанс на победу) рассчитывается как отношение выигранных симуляций к общему количеству итераций:
   $$Equity = \frac{Wins}{Total Iterations} \times 100\%$$
4. **Точность**: При 100,000 итераций статистическая погрешность составляет менее **±0.1%**, что позволяет видеть даже минимальные риски.

### 🚀 Основные компоненты

* **Hand Evaluator**: Функция присваивает каждой руке уникальный числовой рейтинг (Score).
    * *Royal Flush*: `9,000,000`.
    * *Straight Flush*: `8,000,000 + старшая карта`.
    * Это позволяет мгновенно сравнивать силу рук.
* **Card Parser**: Автоматически распознает ранг и масть карты, извлекая данные из имен файлов изображений.
* **Dynamic Deck**: Система учитывает "мертвые карты", исключая их из генерации случайных исходов.

### 📌 Принцип работы интерфейса

* **Hero Hand**: Выберите две карты для расчета ваших шансов.
* **Board**: Добавляйте карты стола, чтобы видеть, как меняется вероятность в реальном времени.
* **Equity Labels**: Система автоматически подсвечивает лучшее действие (Raise/Call/Fold) на основе математического ожидания.

## 🛠 Установка

### Требования:
* PHP 7.4+
* Любой веб-сервер (Nginx, Apache) или локальная среда (XAMPP).

### Пошаговая установка:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Sapvit/roulette.git
   cd roulette
   ```

2. Запустите встроенный PHP-сервер:
   ```bash
   php -S localhost:8000
   ```

3. Откройте в браузере:
   ```
   http://localhost:8000
   ```

4. Выберите интересующую вас игру из главного меню.

## ⚠️ Дисклеймер

Данное программное обеспечение предназначено исключительно для **образовательных и статистических целей**.

* Рулетка: Математика рулетки подразумевает преимущество казино (Зеро), будущие события никак не связаны с предыдущими.
* Покер: Калькулятор служит для обучения, но не гарантирует выигрыш в реальных условиях.
* Никакая статистика не гарантирует выигрыш в азартных играх. Будьте ответственны в своих действиях.
